# UI System V3.1

德馨星云采用固定浅色的现代办公视觉。页面应优先表达业务层级、数据状态和操作关系，不使用模块专属装饰色。

## Tokens

- 品牌与导航：海军蓝 `#0A2340`
- 主要操作：青绿 `#0D7580`
- 页面背景：`#F5F7F9`
- 内容表面：白色
- 正文：`#172B3F`
- 辅助文字：`#687786`
- 边框：`#DDE4EA`
- 功能辅助色：信息蓝 `#2F6FAB`、智能靛蓝 `#5865A8`、关注琥珀 `#A96F16`、成功绿 `#2F7D5B`、危险珊瑚红 `#C4474E`
- 页面遵循约 70% 中性表面、20% 蓝灰层级和 10% 品牌或辅助色；辅助色不得按模块随机分配
- 客户等级是正式业务分类色例外：S 金色、A 青绿、B 信息蓝、C 暖灰；列表和详情统一使用 `CustomerLevelBadge`

颜色只能在全局令牌和受控图表调色板中定义，业务 TSX 不得直接写十六进制颜色。

## Shape and hierarchy

- 菜单和分段控件使用 4px 圆角。
- 输入框、按钮和普通容器使用 6px 圆角。
- 弹窗、抽屉和浮层使用 8px 圆角并允许唯一的浮层阴影。
- 头像和状态徽标可使用圆形或胶囊形。
- 普通内容使用边框和间距区分层级，不使用渐变、光晕、悬浮上移或大阴影。

## Typography and components

页面标题为 24px，分区标题为 16–18px，正文和表单为 14px，表格正文为 13px，辅助信息为 12px。除紧凑徽标外不得低于 11px。

新页面优先复用 `PageContainer`、`PageHeader`、`Section`、`Toolbar`、`StatusBadge`、`Metric`、`FormField`、`EmptyState`、`InlineAlert` 和 `DialogSurface`。运行 `npm run check:ui` 可阻止旧视觉模式重新进入业务组件。

桌面端固定紧凑密度，不再根据历史 `density` 偏好改变行高。业务表格使用 `BusinessDataTable V3`，个人视图可保存列顺序、列宽、固定列、排序、筛选与 20/50/100 分页规格。成功反馈使用 Toast，危险操作使用 `ConfirmDialog`，可编辑长表单接入 `UnsavedChangesGuard`。

## 导航与德小馨

- 桌面侧栏展开宽度为 232px，窄栏为 64px；完全隐藏状态仍保留固定恢复按钮。
- 展开侧栏一次只展示一个业务分组，默认打开当前路由所属分组；窄栏只展示业务分组图标并通过浮层提供具体入口。
- 导航链接关闭批量自动预取，仅在悬停或键盘聚焦具体入口时预取。
- 德小馨默认只显示一个 56px 浮动头像。完整对话面板只在点击后加载，最小化、关闭和 Esc 都返回头像状态。
- 德小馨在登录页、完整 AI 工作区和公开客服嵌入页不加载；头像使用透明 WebP，不再使用旧的大尺寸图片。

## 加载性能约束

- 登录后的员工、角色、最终权限、偏好、未读数和待办数由单个 `AppBootstrap` 查询返回，并在同一服务端请求中复用。
- 常用列表默认不得超过 50 行，任何初始列表不得超过 100 行；筛选、排序和翻页优先在数据库执行。
- 库存批次、流水等互斥标签页只加载当前标签的数据。图表、导出和完整 AI 面板按需加载。
- 运行时函数与数据库保持同区，用户 RLS 结果不得做跨账号缓存。

## 移动任务工作区

移动端固定为“首页、待办、新建、德小馨、我的”五入口，重点处理审批、轻量申请、销售订单草稿和业务查询。扫码仅在用户主动点击后请求相机权限。凭证、银行对账、报表配置、权限和批量主数据维护等复杂能力提示转到桌面端；本阶段保持在线使用。

## 视觉回归

视觉基线覆盖 375、768、1440 和 1920 四档宽度。公共登录页可直接执行；登录后关键模块需要先保存仅供本机使用的 Playwright 登录状态：

```bash
npm run test:visual
PLAYWRIGHT_AUTH_STATE=.auth/employee.json npm run test:visual:update
```

CI 可使用专用非生产账号的 `VISUAL_TEST_EMAIL` 与 `VISUAL_TEST_PASSWORD` 临时生成登录状态；缺少登录状态与测试账号时，登录态视觉测试必须失败。

`.auth/`、测试结果和 HTML 报告均已排除在版本控制之外，禁止提交真实账号会话。
