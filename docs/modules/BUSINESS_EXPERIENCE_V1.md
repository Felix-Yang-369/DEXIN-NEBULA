# 业务能力与用户体验 V1

## 业务能力

- 采购控制塔：询价范围、供应商报价、评分、到货质检、采购退货和订单—入库—发票三单匹配。
- 精细库存：仓库库位、批次移位、FIFO/FEFO策略、批次成本、库存价值和临期数量。
- 客户经营：客户公海、领取与释放记录、信用额度、账期、风险等级和销售订单信用拦截。
- 业财自动化：应收/应付业务单据按科目规则生成凭证草稿，继续沿用独立审核、过账和期间控制。

所有新业务表均启用RLS并显式授权读取，所有写入通过校验身份、组织和业务状态的事务函数完成。

## 用户体验

- PWA：支持添加到桌面；Service Worker仅缓存版本化静态资源，不缓存登录后的业务页面和接口数据。
- 表单设计器：支持文本、数字、日期、选择、长文本和复选字段，表单定义版本化，提交载荷限制为64KB。
- 打印模板中心：统一管理报价单、销售订单、采购订单、出库单、对账单和凭证的纸张、方向、Logo及水印。

## 上线顺序

1. 依次应用 `202608261857xx` 与 `202608261919xx` 六条迁移。
2. 用采购、仓储、销售、财务、管理员五种账号完成RLS验收。
3. 配置客户信用额度、仓储策略和业财科目规则。
4. 以一张测试采购订单完成询价、入库、质检、发票、匹配、退货测试。
5. 以一张测试应收和应付单生成凭证草稿并完成审核、过账。
6. 生产环境部署后验证PWA安装，确认浏览器离线缓存中不包含业务HTML或接口响应。
