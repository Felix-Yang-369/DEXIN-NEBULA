# 版本路线图

路线图记录后续优先级，不代表功能已经完成。当前正式版本见 [发布记录](../releases/2026-08-12-production.md)。

## P0：正式版本稳定与验收

1. 保存可复现的正式版本代码记录。
2. 使用老板、财务主管、客服和仓储账号完成权限验收。
3. 验证登录、Dashboard、CRM、销售、库存、财务和文件下载。
4. 建立数据库备份、恢复验证和部署回滚记录。
5. 对已合并的收付款、小程序、加载状态和导航改版进行业务验收。

## P1：真实业务闭环

1. 用少量真实单据贯通销售、出库、应收和收款核销。
2. 贯通采购、入库、应付和付款核销。
3. 验证库存扣减、凭证、账龄和毛利口径。
4. 修复空状态、重复提交、错误反馈和移动端关键流程。
5. 明确金蝶协同边界，不重复建设成熟会计能力。

## P2：V0.10 运营管理

1. 建立新媒体账号和品牌主数据。
2. 建设内容、素材、审核和发布计划。
3. 建设企业宣传资料与版本管理。
4. 建设企业活动立项、预算、执行和复盘。
5. 平台接口明确后再建设数据分析和舆情监控。

## 上线门槛

- 需求和验收标准明确。
- 核心角色权限验收通过。
- 自动检查、相关测试和生产构建通过。
- 数据库迁移、备份与回滚路径明确。
- 敏感文件与财务数据访问验证通过。
- 手机和电脑完成核心流程验收。
- 发布内容写入 `docs/releases/`。
