# 德馨星云色彩系统

德馨星云采用“深海军蓝 + 星云青 + 日曜金”的企业软件配色。海军蓝表达可信、稳定与数据安全；星云青表达连接、流动与智能；日曜金延续 Logo 中的识别点，只用于品牌强调和高价值提示。

## 状态色

状态色不与品牌色混用，确保业务含义稳定：

- 成功：`#16856D`
- 警告：`#D9971E`
- 危险：`#D65D67`
- 信息：`#397FC0`

## 使用原则

1. 大面积深色只用于侧边栏、登录品牌区和经营 Banner。
2. 内容区域保持冷白灰，保证长时间办公的可读性。
3. 主按钮使用深青色，数据图表优先使用青、蓝、金组合。
4. 金色占比控制在页面可见面积的 5% 以下，不作为普通按钮底色。
5. 红、橙、绿仅用于错误、预警和成功状态，不承担普通装饰作用。
6. 文字和背景保持可读对比度，重要状态同时配合文字或图标表达。
